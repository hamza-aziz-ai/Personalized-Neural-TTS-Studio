# Required BITS Virtual Lab evidence

Do not replace this file with a fabricated screenshot. Before final portal upload:

1. Open a BITS Virtual Lab terminal and upload/extract the standard submission.
2. Use Python 3.10-3.13 and run `python -m pip install -r requirements.txt`.
3. Run `python download_models.py` (or upload the four files from the offline package).
4. Run `python -m streamlit run app.py --server.address 0.0.0.0`.
5. Generate one sample and capture a screenshot that visibly includes:
   - the BITS Virtual Lab/browser or terminal context,
   - the Group 16 app title,
   - the generated audio player,
   - response time, duration, and RTF.
6. Save it here as `bits_virtual_lab_result.png` without cropping away the lab evidence.

The locally verified application screenshot is supplied separately as
`streamlit_app_result.png`; it must not be relabelled as Virtual Lab evidence.
